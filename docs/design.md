# 滇南同行：产品与技术设计

## 目标

为六人云南国庆旅行提供一个私密、手机优先的协作空间。第一版覆盖行程查看、租车方案比较、住宿候选投票和评论，并为实时同步预留 Supabase 数据层。

## 使用与权限

- 单次旅行，一个私密邀请码进入空间，成员使用昵称识别。
- 管理员维护正式行程并管理候选内容。
- 普通成员可以浏览、提出住宿/租车候选、投票和评论。
- 每个候选支持赞成、反对、取消投票；同一成员同一候选只能保留一个投票状态。

## 页面结构

- 顶部：旅行名称、日期、同步状态和当前成员。
- 行程：按日期的纵向时间线，显示地点、活动、交通和状态。
- 租车：方案卡片，显示车型、座位数、时间、价格、押金、备注、链接和投票。
- 住宿：按晚次的候选列表，支持城市筛选、投票、评论和外部链接。

## 技术路线

- React + Vite，静态构建，部署到 GitHub Pages。
- Supabase Postgres + Realtime 作为多人数据层。
- 生产环境使用 RLS：邀请码只允许加入对应旅行空间；成员只能修改自己的投票和评论；管理员可以维护正式内容。
- 实时订阅失败时，前端退回轮询和手动刷新，保证海外网络不稳定时仍可使用。

## 数据模型（下一阶段）

`trips`、`members`、`itinerary_items`、`car_options`、`stay_options`、`votes`、`comments`。所有业务表通过 `trip_id` 归属旅行空间。
